# **NETWORK SIMULATION**
**Instructions:**
1. Open Cisco Packet Tracer and open a new workspace.
2. Select and place two PCs (End Devices) onto the workspace.
3. Select and place one Switch (Intermediary Device, e.g., the 2960 model) into the
workspace.
4. Use the correct Network Media to connect both PCs to the Switch.
5. Configure static IP addresses for both PCs so they are on the same network:
a. PC0: IP Address 192.168.1.10, Subnet Mask 255.255.255.0
b. PC1: IP Address 192.168.1.11, Subnet Mask 255.255.255.0
6. Open the Command Prompt on PC0 and use the ping command to test connectivity to PC1
(type ping 192.168.1.11).

**Deliverables:**
1. A screenshot of your Packet Tracer workspace showing the two PCs connected to the
Switch with green link lights.
